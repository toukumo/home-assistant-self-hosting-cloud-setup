기존 Cloud 서버 연결 준비

이 페이지는 Mac 또는 PC의 브라우저에서만 실행됩니다. 기존 서버의 공개 연결 자료를 사용해 새 HAOS 설치 앱에 전달할 파일을 만듭니다. 서버 계정이나 설정은 변경하지 않습니다.

주의: 현재 서버는 한 번에 하나의 Home Assistant 연결만 지원합니다. 기존 HA가 연결된 상태에서 새 HAOS를 연결하면 새 연결이 거부되거나 원격 접근이 충돌할 수 있습니다. 기존 HA를 운영 중이면 전환 계획을 확인하기 전 로그인하지 마세요.

이 도구는 HTTPS 기본 포트의 단일 API 호스트와 RSA 공개키를 사용하는 기존 서버에 적합합니다. CA 인증서와 JWT 공개키는 직접 신뢰할 수 있는 경로에서 받아야 하며 지문 확인은 서버 동작을 검증하지 않습니다.

서버 관리자가 신뢰할 수 있는 경로로 제공한 CA 인증서와 JWT 공개키를 선택하세요. 개인키나 계정 파일은 선택하지 마세요. URL만으로 서버의 공개키를 안전하게 확인할 수 없습니다.







HAOS 앱 스토어에 공개 저장소 https://github.com/toukumo/home-assistant-self-hosting-cloud-setup를 추가하고 Self-hosted Cloud setup을 설치하세요. 앱에서 다운로드한 파일을 선택합니다. 신규 HA 설정에만 적용되며 기존 Cloud 자료가 있으면 설치를 거부합니다. 설치 후 기존 Cloud 계정으로 로그인하세요.
